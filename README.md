# Code-Tantrum 😤

A browser extension that hides CodeTantra's SensAI assistant popups and idle nag prompts.

## Features

- Hides the “Are you stuck?” idle nag, SensAI chat panel, MCQ helper toolbar, and floating mascot.
- One toggle turns blocking on or off without refreshing.
- Dark and light popup themes.
- Runs locally with no data collection or external requests.

## Installation

1. Download this repository with **Code → Download ZIP**.
2. Extract it.
3. Open `chrome://extensions`, `edge://extensions`, or the equivalent extensions page.
4. Enable **Developer mode** and choose **Load unpacked**.
5. Select the extracted repository folder.

For Firefox, open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and select `manifest.json`.

This is an unofficial independent project and is not affiliated with or endorsed by CodeTantra. It only hides UI elements locally; it does not modify submissions, grades, or server-side behavior.
